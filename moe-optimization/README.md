# MoE 训练优化

一个 MLA + KDA 混合注意力 + MoE 的模型，在 TPU v7x 上从单片调到多片的训练优化：每一项优化做什么、依赖谁、值多少、为什么有效。共 13 章专题，加一页宣传页。

## 构建

```bash
python3 build.py --check     # 构建到 out/，并检查站内链接和锚点
python3 -m http.server -d out 8000
```

只依赖 Python 3 标准库。`build.py` 与 `tpu-cluster-handbook/build.py` 是同一份脚本，书和书之间的差别都写在 `book.json` 里。

## 文件布局

| 路径 | 内容 |
|---|---|
| `book.json` | 唯一的目录：书名、页面顺序、标题、侧栏文字、页脚 |
| `pages/` | 每页的正文，只有 `<article>` 里面那一段。首页和宣传页（`standalone`）存的是整页 |
| `static/` | 样式、脚本、插图和动图，构建时原样拷贝 |

`out/` 是构建产物，不要手改，也不要提交。

## 写作口径

- 步时用指数表示（大号模型单片 BF16 最初基线 = 100，越小越快），百分比按档取整；硬件属性（ms / GiB / TFLOP）照写。
- 不写合作方名称、模型真名和能反推模型规模的数字；片数、日期按书里已有的写法模糊。
- 拿不准的标 `[推断]` / `[需验证]`。
