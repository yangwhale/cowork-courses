# 万卡级 TPU7x 集群交付参考手册

一本书分三栏：**交付手册**（按交付顺序的操作步骤）、**讲义**（同一章的讲课版，和手册一一配对）、**经验教训**。

## 构建

```bash
python3 build.py --check     # 构建到 out/，并检查站内链接和锚点
python3 -m http.server -d out 8000
```

只依赖 Python 3 标准库。

## 文件布局

| 路径 | 内容 |
|---|---|
| `book.json` | 唯一的目录：栏目、页面顺序、标题、侧栏文字、手册和讲义的配对、讲义时长、旧地址跳转 |
| `pages/` | 每页的正文，只有 `<article>` 里面那一段。首页和宣传页（`standalone`）存的是整页 |
| `static/` | 样式、脚本、插图、动画、示例脚本，构建时原样拷贝 |
| `build.py` | 生成页框、侧栏、面包屑、本页目录、上一页 / 下一页、手册↔讲义切换条、搜索索引和跳转页 |

`out/` 是构建产物，不要手改，也不要提交。

## 常见改动

- **改正文**：直接改 `pages/` 下对应文件。标题要带 `id`（目录和锚点靠它），格式照抄同文件里已有的 `<h2>` / `<h3>`。
- **加一页**：在 `pages/` 下放正文，再往 `book.json` 的 `pages` 里按阅读顺序插一条。
- **改页名或挪位置**：旧地址往 `book.json` 的 `redirects` 里加一条，别让外面的链接失效。
- **加插图**：放进 `static/` 对应目录，用相对路径引用。
